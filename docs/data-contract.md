# 物理设计成本目录

成本、权重与维护费用用非负有理字符串；bytes 为非负整数，预算包含全部已选候选，不按引用次数重复收费。requires 为必需候选集合且依赖递归闭合，互斥 group 中最多选一项，None 无互斥。每查询有至少一个空 requires 基线；选择全部可用方案中 cost 最低，同费用按 plan ID 字典序给确定解释。

目标为 sum(weight*selected_cost)+maintenance_coefficient*sum(maintenance)，第二目标 bytes，第三为升序候选 ID 列表字典序。mandatory 必须计费，即使零收益。构建器是本地可信 Python 映射，通过逻辑步骤返回 actual_bytes、内容摘要及受控失败，不执行清单 shell；所测字节超该候选计划值或者总预算任一超出均阻断，不以其他未用预算悄悄更换计划。

本材料 dict 与 sortA 组合共同服务 q1，dict 另服务 q2；sortA/sortB 互斥，must 零收益但必选。storage7 恰容 dict+sortA+must。初始工具只清点候选、查询、数字预算，不求解最优、构建副本或切换路由。

## 规划器语义（warehouse_data.planner）

- **输入错误先于求解**：候选依赖成环、requires/mandatory/方案引用未知候选、查询缺空集基线、有理字符串非法、builder 未覆盖全部候选，均在 `model.parse_problem` 抛 `InputError`，issues 为可逐条复核的中文原因。
- **方案选择**：给定候选集合后，每查询仅在 requires 全部满足的方案中取最低 cost；多候选收益不做可加性假设，共享同一字典只收一次存储。未选中方案在输出中给出排除原因（缺哪些依赖，或费用不优于选中方案）。
- **硬约束**：存储预算、维护预算、必选项闭合、互斥组。必选闭合本身违反约束即全局无解，证书给出必选闭合成员、实测/计划数字与被违反的具体预算或互斥组。
- **分支定界**：必选闭合预置为根节点，仅在含必选闭合的可行空间分支。乐观下界把未决候选视为免费可得（维护费与字节只计已确定部分），因此对该节点下任意完整可行解都是合法下界；f1 严格更差或 f1 相同但字节下界更大才剪枝，第三目标平局不剪以保留可证最优。
- **终止语义**：搜索耗尽为 `optimal`，差距 0；`--timeout`/`--node-limit` 触发为 `incumbent_only`，附当前可行解、由全部前沿节点乐观下界最小值给出的全局下界与差距，不宣称最优。无可行解为 `infeasible`，附冲突证据。

## 独立验证（warehouse_data.verify）

验证器不 import planner 的评分或枚举函数，自带闭合、互斥、预算、每查询选路与三级目标的重算逻辑：

1. 重算选中集合的闭合性、互斥、双预算与 f1/字节，逐查询核对方案与排除原因；
2. 候选数不超过上限时全枚举 2^n 个闭合子集，独立得到字典序最优并与报告逐项对照；
3. `incumbent_only` 核对全局下界不超过任一可行解目标值且差距自洽；
4. `infeasible` 独立重算必选闭合并核对证书数字；伪造数字或遗漏冲突会被拒绝。

## 构建与切换（warehouse_data.builder）

- 按 `topo_order` 中属于选中集合的候选依次构建；实测字节 > 该候选计划 bytes、缺摘要、builder 受控失败均阻断，暂存产物不登记为可用。
- 累计实际字节在每步及全部完成后各复核一次，超过存储预算即阻断，不挪用其他候选的未用预算。
- 切换前短事务复核：在线基准目录未漂移、清单 sha256 与规划时一致、双预算仍满足；随后 `os.replace` 原子替换 `current` 符号链接。任何复核失败都保留旧目录，查询不改变路由，逻辑表名与内容不变。
